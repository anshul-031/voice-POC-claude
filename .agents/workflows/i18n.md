# Internationalization (i18n) Workflow

Use this workflow when adding, modifying, or reviewing any user-facing text.

## Rules

1. **No hardcoded strings** — never embed user-facing literal strings, prompts,
   labels, error messages, or toast text directly in code.

2. **Use `UI_STRINGS`** — import from `src/constants/uiStrings.js`:
   ```js
   import { UI_STRINGS } from '../constants/uiStrings.js';
   ```

3. **Template placeholders** — for dynamic values, use function entries:
   ```js
   UI_STRINGS.toasts.callStarted(agentName)
   UI_STRINGS.errors.notFound(resourceName)
   ```

4. **Tests** — assert against `UI_STRINGS` constants, not hardcoded strings:
   ```js
   expect(result.message).toBe(UI_STRINGS.errors.unauthorized);
   ```

## Steps

1. Identify all new or changed user-facing text in the changeset.
2. Add or update entries in `src/constants/uiStrings.js`.
3. Replace any inline string literals with the corresponding `UI_STRINGS` reference.
4. Update related tests to assert against `UI_STRINGS`.
